FlensSabers Live-Remote – Firebase-Version + Trainer-WebApp
==========================================================

Diese ZIP ist direkt mit deinem Firebase-Projekt verbunden.

Aktiv:
- Trainer-Fernbedienung: trainer.html
- Passwort für die Trainer-Seite: admin
- Live-Ticker auf members.html
- Live-Kalender auf members.html
- Speicherung und Live-Synchronisierung über Firebase Firestore
- trainer.html ist jetzt als installierbare WebApp vorbereitet
- eigenes FlensSabers Trainer-App-Icon ist enthalten

Wichtig:
- Änderungen auf trainer.html werden nach dem Speichern live auf members.html angezeigt.
- Alle Geräte greifen auf dieselben Daten in Firestore zu.
- Auf unterstützten Browsern kann die Trainer-Seite direkt als App installiert werden.
- Auf iPhone/iPad: Safari öffnen > Teilen > Zum Home-Bildschirm.

Empfohlene Firestore-Regeln (Beispiel – anpassen, wenn du später echten Login willst):
--------------------------------------------------------------------------
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /flenssabers_live/{document=**} {
      allow read, write: if true;
    }
  }
}
--------------------------------------------------------------------------

Hinweis:
Der Admin-Schutz mit Passwort 'admin' läuft im Frontend der Trainer-Seite.
Das ist bequem, aber kein vollwertiger Hochsicherheits-Login. Wenn du später willst,
kann ich dir dafür auch noch eine echte Firebase-Authentication-Version bauen.
